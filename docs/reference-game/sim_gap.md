# The own process's gap list

Generated by `tools/reference-game/scripts/sim_gap.py`; do not edit (regeneration: [docs/functions/README.md](../functions/README.md#the-sim-gap-list)). The original functions that the own DBSIM (`sim/`) still reaches without a service row or a hook: the dispatch refuses them and the run stops there. Counts are facts of the sources named below; the roles of the functions are not claimed here (see [the function index](../functions/index.md)).

## Sources and method

- Executable: `VER95/DBSIM.EXE` ([reference_version.md](../reference_version.md)). Call graph: 3010 function starts of the synchronized descent (`dbsim_map.py` over `probe_instruction_inventory.py`): direct calls, tail calls and jump tables are followed, calls through pointers are not; an instruction count is the descent's per function (a tail-called start is not included).
- Service rows: the fragments of `sim/dispatch/services/`; hooks: `hook_registry.h` (RVA + image base).
- Guest-call sites of `sim/src`: 1838 with a constant VA (517 distinct VAs; `A ? B : C` arguments count each constant) in 37 files, 136 dynamic (the VA is read from an object or a variable). 61 wrappers found: functions and macros that pass a parameter to the VA slot of `es2_sim_call` or of another wrapper (fixpoint over all files).
- Bridged calls of the hook adapters: 684 distinct VAs (`"call_<va>"` counters of `tools/reference-game/proxy/*.h`); 2 of them are no function but the address of an indirect call instruction (`FF /2`) that an adapter uses as the key of a call through a pointer, whose target the dispatch sees instead, so they are no roots: `420a8d` (sim_leaves_hooks.h), `420acb` (sim_leaves_hooks.h).
- Function-pointer tables: 125 addresses that `sim/src` names which begin a run of base-relocated code pointers in the image (vtables, callback slots).
- Live column: `map.json` of the current DBSIM map ([dbsim_map.md](dbsim_map.md); number of the 40 suites with a nonzero entry count; the map lists only live, unreplaced functions; `0` = probed and never entered).

**Called**: a VA that own code passes to the dispatch (or a hook adapter bridges) with neither a row nor a hook; when that path runs the run stops. **Behind**: original functions that the called ones reach in the call graph, again without row or hook (breadth-first, stopping at rows and hooks): what an own replacement of the called function may still have to call, an upper bound. **Virtual**: targets of the function-pointer tables that `sim/src` names (own code installs the table and calls its slots through an object, which no call site shows), with their own behind; a target only matters when a slot is called, which a reading of the use decides. **Referenced only**: code addresses that `sim/src` names but never passes to a call (tables, comparisons, variables, return-address constants).

## Verdicts

A VA of the gap keeps no row when a document gives the reason; the verdict list `tools/reference-game/scripts/sim_gap_verdicts.json` names the VA, the kind and the section. **dead**: no own path makes the call (the slot is never called on such an object, the branch is never taken); **caller-replaced**: the callers are own code that does not make the call; **behind**: reached only through other refused VAs; **served**: own code serves the effect elsewhere (another row, the process record). A verdict is a reading of the sources, not a run; the dispatch still refuses the VA. **Open**: neither row, hook nor verdict.
